# 루틴 트래커

매일 루틴을 체크하고, 한 달 달성률을 그래프로 보는 웹 앱입니다.
구글 스프레드시트로 만든 "월간 루틴 체크표"와 기능이 같고, 색과 가독성을 다듬었습니다.

## 실행 방법

설치할 것은 없습니다. HTML·CSS·JavaScript 파일만으로 동작합니다.

1. VS Code에서 이 저장소 폴더를 엽니다.
2. `routine-tracker/index.html` 파일을 브라우저(크롬 등)로 엽니다.
   - 방법 A: 파일 탐색기에서 `index.html`을 더블클릭합니다.
   - 방법 B: VS Code 확장 프로그램 **Live Server**를 설치하고, `index.html`에서 마우스 오른쪽 버튼 → **Open with Live Server**를 누릅니다. 코드를 저장할 때마다 브라우저가 자동으로 새로고침되어 수정하기 편합니다.

## 기능

| 기능 | 설명 |
| --- | --- |
| 월·연도 선택 | 위쪽 1월~12월 탭으로 이동합니다. 탭 아래 숫자는 그달 달성률입니다. |
| 루틴 체크표 | 1일부터 7일씩 Week 1~5로 나눴고, 오늘 날짜 칸은 노란색으로 표시됩니다. |
| 루틴 편집 | 이름을 눌러 바로 고칩니다(이모지 가능). `+ 루틴 추가`로 추가하고, 줄에 마우스를 올리면 나오는 `×`로 삭제합니다. 루틴은 최대 20개입니다. |
| 분석 | 루틴마다 목표(그달 일수), 실제(체크한 수), 남음, 진행률을 보여줍니다. |
| 요약 | 이번 달 목표·완료·남음 합계와 달성률 도넛 그래프입니다. |
| 일일/주간 진행률 | 날짜별, 주별로 루틴을 몇 % 완료했는지 막대그래프로 보여줍니다. |
| 컨디션 | 기분·에너지 칸을 누를 때마다 1→2→…→5→빈칸으로 바뀌고, 선 그래프로 흐름을 보여줍니다. |
| 주요 루틴 TOP 10 | 이번 달 가장 많이 체크한 루틴 순위입니다. |
| 백업 | `백업 저장`으로 기록을 `.json` 파일로 내려받고, `백업 불러오기`로 복원합니다. |

새 달을 처음 열면 가장 최근 달의 루틴 목록을 그대로 가져옵니다(체크 기록은 비어 있음).

## 데이터는 어디에 저장되나요?

브라우저의 **localStorage**(웹사이트가 내 컴퓨터 브라우저 안에 작은 데이터를 저장해 두는 공간)에 자동 저장됩니다.
그래서 서버나 로그인 없이도 창을 닫았다 열어도 기록이 남습니다. 다만 다음을 알아 두세요.

- 다른 브라우저나 다른 기기에서는 기록이 보이지 않습니다. 옮기려면 백업 파일을 사용하세요.
- 브라우저의 "인터넷 사용 기록 삭제"에서 사이트 데이터를 지우면 기록도 지워집니다. 가끔 백업해 두세요.

## 파일 구조

```
routine-tracker/
├── index.html   화면 뼈대(어떤 칸과 카드가 있는지)
├── style.css    색과 배치. 맨 위 :root 안의 색상 값만 바꾸면 전체 테마가 바뀝니다.
└── app.js       동작(체크 저장, 진행률 계산, 그래프 그리기)
```

## 바꿔 보기 좋은 곳

- 기본 루틴 목록: `app.js`의 `DEFAULT_ROUTINES`
- 최대 루틴 수: `app.js`의 `MAX_ROUTINES`
- 포인트 색(보라색): `style.css`의 `--accent`, `--accent-2`
- 다크 모드 색: `style.css`의 `@media (prefers-color-scheme: dark)` 부분(컴퓨터가 다크 모드이면 자동 적용)
